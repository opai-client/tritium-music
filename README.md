# Tritium Music

这是一个来自我的客户端 [Tritium-X](https://github.com/IzumiiKonata/Deuterium) 中的音乐播放器的 Opai 移植。  
该播放器使用网易云音乐作为音乐内容提供商。  
为 Opai 做了灵动岛适配。
